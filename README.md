# Lead Management System

A full stack MERN application where users can manage business leads easily.

## Features

- User registration
- Dashboard after register
- Add new leads
- Edit leads
- Delete leads
- Search leads

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB

## How to Run

### Backend
Run in backend/server folder:
```bash
npm install
npm run dev
```

### Frontend
Run in frontend/client folder:
```bash
npm install
npm run dev
```
